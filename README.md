# Stampio

Stampio is a tiny web app for logging when things happen — wake-up, lunch, meditation, naps, anything.
Tap an activity's button to record the current time. Built to be added to the iPhone home screen.

- **Track**: one button per activity; tap to log (with Undo). **Edit** to rename, recolor or delete an activity; **New activity** to add one.
- **Chart**: one line per activity; x-axis is the day, y-axis the time of day. Tap chips to choose which activities to show; 7D / 30D / 90D / All ranges; summary table with average, earliest and latest time.
- **History**: every timestamp grouped by day. Tap one to change its time or delete it; **+ Add** to log one you missed. **Export CSV** / **Import CSV** (import merges and skips duplicates — handy for backups).

All data lives in `localStorage` on the device. Nothing is sent anywhere.

## Develop

```sh
npm install
npm run dev      # http://localhost:5173 (also printed with your LAN IP)
npm run build    # outputs static files to dist/
```

To try it on your phone, open the LAN address that `npm run dev` prints while on the same Wi-Fi.

### Sample data (dev only)

With `npm run dev` running, open the browser console:

```js
seedTestData()      // 30 days of realistic sample timestamps for every activity
seedTestData(90)    // or any number of days
clearTestData()     // remove the sample data; your own logs are kept
```

Re-running `seedTestData` replaces the previous sample data instead of adding more. Known names
(wake, lunch, nap, meditation, coffee, dinner, bed, gym…) get realistic times; other activities get
a consistent made-up time of day. These helpers aren't included in `npm run build`.

## Put it on your iPhone home screen

1. Host `dist/` on any static HTTPS host (GitHub Pages, Netlify, Vercel, Cloudflare Pages). For example, drag the `dist` folder onto https://app.netlify.com/drop.
2. Open the URL in **Safari** → Share → **Add to Home Screen**.
3. Launch it from the home-screen icon. It opens full screen and works offline.

**Notes**
- The home-screen app has its **own storage**, separate from Safari. Data logged in Safari won't appear in the installed app, and the other way round.
- Export a CSV now and then as a backup. Deleting the home-screen app deletes its data.
- Keep using the same URL: storage is tied to the site's address.

## CSV format

```
activity,timestamp,date,time,weekday
Lunch,2026-10-26T12:41:07+01:00,2026-10-26,12:41:07,Mon
```

Import only needs the `activity` and `timestamp` columns.

App icons are generated by `node scripts/make-icons.mjs`.
